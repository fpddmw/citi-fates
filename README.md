# 符文构筑 Roguelike：策划与技术验证

正式游戏名称待定。当前分支为 `codex/rune-roguelike-plan`，于 2026-09-26 独立建立。

玩家在 Roguelike 战斗中获得承载真实词义的符文，在法杖中组合成技能，并借助魔法精灵、投入的符文和可选提示词进行定向融合。成长围绕词条本身及其位阶展开。核心体验是用熟悉的词语构筑能力，在战斗中发现合乎词义、又超出预期的作用关系。

本作重点验证：模型能否理解词义及玩家意图，自主提出关系，构造可执行行为，并使用已有资源组织与行为一致的整体演出。底层代码提供可组合的对象、状态、事件与关系能力；已确认技能由程序执行并稳定保存。

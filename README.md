## 当前构想

一座持续运行的后末日城市，主要人物分布于不同地点，周围还有其他居民、组织、帮派与权力关系。人物不全住在安全区；全城幸存者按用户倾向考虑数百人、最多约一千人，准确人数、谷地统计范围及主要 NPC 数待定。玩家扮演身份尚未确定的高维存在，通过有限的环境交互影响他们，无法直接控制其行动。

世界风格参照《湮灭》《我是传奇》：美丽、陌生、生命旺盛，冷峻而疏离，熟悉的城市、农场和地球生命仍然存在。自然按一致规则运行，危险没有道德目的；人物与玩家关心自己的生活和命运。

当前背景沿外星飞船携带的“播种系统”展开：科技造物通过预先设计的工程生物改造环境，使其适合外星生命生活。已认可的机制方向是湿润地表、活体基质和水系变化，辅以活动型工程载体；原生生态与工程生命共同存在。系统不自动快进演化，具体生物、物质、速率和能力仍需细化。

已认可的历史框架：人类有效抵抗但维护范围不断扩大，多地区先后收缩，原有工业与公共服务网络长期断裂，仍有文明火种。本城在一次汛期水系失控后大规模撤离；少数人依托可维护的土地、水源和设施继续生活。危险需要有节律、征兆和反应时间，结局希望承接幸存者度过一次极端危机后继续生活；具体危机与参数未定。

已认可的城市方向：丘陵与河流平原交界的中小型城市，河流湿地、低洼旧城、高处城区及外围农田林地交错，原有建筑与地球生命仍可辨认。用户明确划分：未被或轻微改造的城市地区为安全区，两者交界处为危险区，完全共生且工程生物活动频繁的地区为禁区。具体分布与边界待设计，全地图自由观察仍然成立。

安全区视觉直接参照《我是传奇》，呈现地球原有生态明显接管人类城市空间的面貌。主要人物不集中在同一坡地街区；助手此前的固定八人职业名单和六处居住点方案未获采用。

当前主线由用户提出：下游禁区观测站工作人员以水文情报交换城内补给。穿城河流与外星生态边界稳定数年后，今年居民争论是否继续冒险送物资。送达可提前获知即将导致城市沦陷的洪水或类似危机；不送也会从后续生态蔓延认识危机。补给是篇幅较短的首个正式事件；上游控水、加固安全区、撤离城市各有完成程度与结局。

当前第一种结局沿用户认可的方向深化：下游工程生态降低排水能力，幸存者尝试不可逆地启用城外应急泄洪通道，牺牲原先受保护的谷地生活条件，争取保住城市。通道长期隔水、谷地排水和基质条件解释其受改造较轻；仍需具体交代局部阻碍、落差、容量和出口。风险包括付出谷地代价后仍未能救城，行动窗口、设施结构及启用方式尚未定案。

城市有自身的主要城郊耕地、水源、住所与通路；谷地是相对可靠但容量有限的生活区域和补充粮源。保城需要保存实际生存条件，分洪后仍需承接粮食损失与迁入人口。保留谷地、撤离城市同样可以成立，其结果取决于安置和继续外迁条件。人口、土地面积和产能尚未核算，不预定牺牲者或唯一最佳结局。

飞船残骸、高维玩家及可能终止灾难、收回改造体是隐藏结局候选。用户明确要求暗示与线索埋入整体叙事，已否定由观测站记录单独引出隐藏线。后期需要多人合作，部分行动可能因失去特定人物而无法完成；具体职责从人物生活与主线关系中设计。

玩家没有实体，直接观看沙盒式 2D／2.5D 大地图，可以查看任何地方正在发生的事情，无需另设高维房间、控制台或接入界面。用户倾向于将其来历设定为某个角色在真结局或某个结局中因事故或牺牲成为高维存在／进入高维空间，感觉参照《星际穿越》；具体人物、成因与时间关系尚未定案。

作品采用多视角、电影式叙事。首周目从跟随一名 NPC 开始学习操作，镜头之外的人物同步活动。玩家逐步发现错过的人、物品和机会怎样影响后续，并将这些认识带入下一周目，争取让不同人物获得更好的命运，最终满足作者设计的完整／完美结局条件。

人物行为和环境作用形成大部分具体过程；作者设计剧情框架、关键条件、分支和触发演出。程序和自动机维护世界与行动，新增 TypeSafe AI 的 Jev／System One 作为人物语义判断的技术候选：在角色所知、经历与既有行动范围内辅助选择，持续意图和实际后果仍由游戏维护。对白、部署、成本及短时读档兼容性待验证，尚未接入或确定选型，详见策划案第 12.6 节。

玩家通过改变环境中的条件，利用对象、动物及人物之间的因果关系间接引导行动。已认可的互动方向分为两类：第一类主动使用对象已有的交互，与角色自动机共用对象规则，表现为物件完成正常操作而执行者缺席；第二类促成已有临界条件下的变化，表现为时机恰好的自然事件。具体对象权限和输入方式待细化。“短暂施加方向力”作为核心玩法的提议已被用户明确否定。

用户明确要求加入“干涉度”，限制玩家持续与现实交互。当前建议采用全局累积、随游戏时间消退的规则，两类主动干涉共同占用额度，观察保持自由；具体计费、恢复、表现和读档衔接规则均标为开发者建议。

短时读档方向：用户已确认只保留最近数分钟的历史，支持局部试错；超出窗口的历史不可通过连续回退重新访问，以保留长期选择的后果。开发者建议恢复全世界到同一历史时刻；具体窗口长度、保存方式及世界观解释仍待决定。

当前优先深化熟悉枢纽、能形成实际做法的人，以及与谷地生活紧密相连的人。前者影响路线能否成立，后者使撤离与代价落到具体生活；现状知识和同行帮助主要影响时间与风险，可由既有角色承担。工具需要从实际用途和故障推导。这些支持不构成固定团队或强制收集顺序，上游设施与生活场景随人物条件共同细化。

旧设施用途不自动代表灾后仍有原班人员、齐全工具或供应能力；人物可冒险、替代和独立行动，主线保持少数具体人物的视角。生物、环境、空间与行为一并考虑，模型和交互需求从设计中形成。仍处策划阶段，不启动搭建、引擎选型或资产制作；具体人数、地图规模及 PC 性能目标尚未定案。

## 阅读约定

策划案明确区分：

- **用户已明确的方向**：后续设计需要承接。
- **当前倾向／体验设想**：可作为讨论基础，细节仍可调整。
- **开发者建议**：为分析提供的方案，尚未成为需求。
- **待决**：暂时没有结论。

示例、初步判断、案例参照及技术候选均不自动成为正式剧情、功能规格或可行性结论。
